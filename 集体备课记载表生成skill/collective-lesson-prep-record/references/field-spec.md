# 字段规范 · 写什么、写多长、怎么断行

> **硬性规定（先读这条）**：下面所有内容都只能写进模板已有的 `{{占位符}}` 里。字数、断行、分条全部靠**调整文字**做到，不许靠改模板实现——不许加行加列、不许改列宽行高、不许调字号行距、不许动模板原有文字。格子写不下就压字数，不是改格子。
>
> 所有内容最终都进 Word 表格单元格，`\n` 会被脚本转成换行符。段落之间不要空行（会撑高行距显得空），靠「一、二、三」「1. 2. 3.」分段即可。

## 一、总表 13 个字段

按模板出现顺序，键名必须与 `{{}}` 中完全一致。

| 字段 | 字数 | 格式要求 | 写什么 |
|---|---|---|---|
| 年级 | — | 如「四年级」 | 用户给，不写「4年级」 |
| 时间 | — | 如「2026年11月4日」 | 用户给；未给用当天日期 |
| 教材内容 | ≤20 字 | 「第X单元 具体内容」 | 不写版本、册次、第几课时；用户给了课时才在后面加「（第X课时）」 |
| 研究主题 | ≤30 字 | 一句话 | 落到本课的核心素养或关键能力上 |
| 中心发言人 | — | **只填姓名** | 与蹲点领导不同人 |
| 蹲点领导 | — | 姓名 | 未给则留空 |
| 参加人员 | — | **写全名单，顿号分隔**，如「张一、王二、李三、赵四」 | 名单上每一位教师都要出现，不用「XX组教师」概括；蹲点领导另有专格，不重复写 |
| 教材解读 | 150–250 字 | 2–3 段，段间 `\n` | 单元位置 → 知识基础 → 教材编排意图 → 对后续学习的作用 |
| 教学目标 | 3 条 | `1.` `2.` `3.` 各一行 | 每条一个动词开头，落到该学科核心素养，第 3 条落到情感/应用 |
| 教学重难点 | 60–100 字 | 「重点：……」一行，「难点：……」一行 | 重点＝知识与技能主线；难点＝学生真正卡住的地方，要具体 |
| 中心发言人发言内容 | 150–250 字 | 3–5 行，一行一个环节 | 本课教学主线（如「复习迁移—自主探究—对比归纳—分层练习」）＋每个环节的关键动作 |
| 备课组成员发言 | 每人 25–50 字 | 每人一行，`姓名：` 开头，共 N 条（N＝参加教师数） | 具体可操作的建议：用哪个情境、加哪道变式、抓哪个错例、怎么分组 |
| 领导发言提要 | 100–200 字 | 2–3 行 | 以蹲点领导口吻：课堂组织、学生参与面、评价反馈、习惯养成，各说一句 |

**易错点**

- `中心发言人` 只写人名，发言内容另有一格，别把两者混在一起。
- `备课组成员发言` 的人数必须等于参加教师人数；蹲点领导不写进这一格。
- `教材解读` 不要写成「本课很重要，要好好上」，要有教材编排逻辑。
- **只给了单元没给课时**：上面这 13 格全部按「二·补 单元整体模式」写，教材解读、教学目标、重难点、发言内容都不要缩到某一课时。

## 二、附件 9 个字段（每位教师一节，全部合并成一个 Word 文件）

| 字段 | 字数 | 格式要求 | 写什么 |
|---|---|---|---|
| 学科 | — | 与总表一致 | — |
| 年级 / 时间 / 教材内容 / 研究主题 | — | 与总表**完全一致** | 复制，不要另写 |
| 教学目标 | 3 条 | 各一行 | 角度可与总表略有差异，突出这位教师关注的点 |
| 教学重难点 | 2 行 | 「重点：」「难点：」各一行 | 允许与总表用词不同，但指向同一处 |
| 教学设计 | 200–350 字 | 课时模式：「一、导入」「二、探究」「三、练习」「四、小结」各一行；**单元模式见下** | 写清每个环节**怎么做**，体现个人风格；不是抄总表发言 |
| 学生活动 | 150–250 字 | 4–5 行，一行一件事 | 学生具体做什么：动手、同桌互说、小组交流、汇报、独立练习、互评 |

> 输出形式：所有教师的这一节由脚本**合并成一份 docx**，每人一页、标题带姓名，输出目录里不再出现单人文件。

**每个人的那一节必须真的不同**

同一课，八个人可以有不同的落点：有人从情境切、有人从操作切、有人从问题链切、有人从错例切。差异要体现在**环节顺序、活动形式、练习层次**上，不能只把导入情境换一个。

## 二·补、只给单元时的单元整体模式

用户只说了「第X单元 具体内容」、没给课时，就**按整个单元**出教研，不自行落到某一课时。四处写法要跟着换：

| 字段 | 单元模式怎么写 |
|---|---|
| 教材解读 | 单元在教材中的位置 + 各板块（课时）的递进与勾连 + 单元整体育人价值；**不写某一课时的例题步骤**；250 字左右 |
| 教学目标 | 3 条按整个单元写，覆盖全单元核心素养（如「建构三个模型」「经历完整建模过程」「形成用模型解决问题的意识」） |
| 教学重难点 | 落在**单元关键处**（如「三个模型的建构与模型间的辨析」），不是某课时的细节 |
| 中心发言人发言内容 | 单元主线：单元结构 → 板块/课时安排 → 关键活动 → 单元评价与作业 |
| 成员发言 | 说整个单元的教法建议（贯穿情境、错例集放在哪、分层练习怎么排），不是某一课时的导入话术 |
| 附件·教学设计 | 四段改为：`一、单元结构梳理` `二、课时安排与主线` `三、关键活动设计` `四、单元评价与作业` |
| 附件·学生活动 | 覆盖单元全程的活动（梳理结构图、分课时探究、单元整理、自评互评），不要只写一节课 |

单元模式下的「同单元异构」：差异落在**单元整体规划**上——有人按模型分块推进、有人按情境线串整单元、有人按「先散后聚」先做各模型再建结构图、有人把评价与作业前置设计。不要八个都写成「先加法模型再乘法模型」的同一条路。

## 三、教研活动记录（第三份产出）

| 项目 | 写法 |
|---|---|
| 活动主题 | 「{年级}{学科}备课组第X周集体备课活动」；用户给了就照用 |
| 活动时间 | 与总表一致 |
| 主持人 | 与总表一致 |
| 教研主题 | 与总表的「研究主题」一致 |
| 参加人员 | 可选，默认＝与总表一致（写全名单），不要就删掉这行 |
| 教研内容 | 800–1200 字，六节条目式 |

`教研内容` 的写法：**专业书面语，只写内容不写人物**。固定六节——`一、教材解读` `二、教学目标与重难点` `三、教学环节与活动设计` `四、形成的共识` `五、常规检查整改要求`（有组长补充才立）`六、蹲点领导意见`（有领导才立），没内容的那节删掉、编号顺延。每节先一句总述再分条，条目用「1. 2. 3.」或「一是……二是……三是……」。

**必须写成结论，不许写成发言**：

- ✗ `楚玉珊：目标三条，第一条落模型意识……` / `王敏：难点我同意定在……` / `大家讨论认为……`
- ✓ `教学目标确定为三条：一是……二是……三是……` / `教学难点有两处：一是……二是……`
- ✗ `通过本次活动，我深刻认识到……` / `今后我要在课堂上……`

正例：

```
二、教学目标与重难点
教学目标确定为三条：一是能在具体情境中辨认总量与分量……发展模型意识和符号意识；二是经历“情境感知—关系抽象—模型建构—迁移应用”的过程……发展运算能力和推理意识；三是感受模型的广泛应用，养成先分析关系再列式的习惯。
教学重点为建构三个基本模型，并会用模型解决实际问题。教学难点有两处：一是总量与分量的相对性；二是复合情境中判断各部分量是否相同。
```

反例（不要）：

```
楚玉珊：目标三条，第一条落模型意识，第二条落推理意识。
王敏：难点定为总量与分量的相对性。
汪雨婷：还有一处难点是判断各部分是否相同。
```

## 五、教师教学侧重池（自动分配用）

名单里没给侧重时，按顺序分配、循环使用，保证同一批人不重复：

| # | 侧重 | 教学设计上的具体表现 |
|---|---|---|
| 1 | 情境生活化 | 真实校园/家庭情境导入，素材贯穿到练习 |
| 2 | 动手操作直观 | 学具、图示、分块涂色，先做后说 |
| 3 | 问题链追问 | 三连问「先做什么—为什么—如果换成…呢」 |
| 4 | 变式与错例辨析 | 收集典型错例，组织判断改错，再变式 |
| 5 | 小组合作交流 | 明确分工、限时讨论、组间互评 |
| 6 | 分层练习辅导 | 基础/变式/拓展三层，巡批关注学困生 |
| 7 | 语言表达规范 | 要求用完整规范的话说清算理/思路/依据 |
| 8 | 知识结构化 | 思维导图、前后知识勾连、单元整体视角 |

人数超过 8 人时，第 9 人起从池子里再挑一个方向做**组合**（如「情境＋分层练习」），角度必须与前面的人错开。
