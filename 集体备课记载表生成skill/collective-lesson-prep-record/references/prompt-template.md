# 每次输入用的提示词

`｛｝` 里的内容换成自己的，**用不上的整行删掉或留空**（留空的按「不填时的默认」处理）。方括号 `｛｝` 请保留成中文括号，别写成英文 `{}`——模板里的占位符是半角，混用会打架。

---

## 标准版（推荐，复制这条改内容）

```text
用 collective-lesson-prep-record 生成集体备课材料。

【基本信息】
学科：｛数学｝
年级：｛四年级｝
教材内容：｛第四单元 三位数乘两位数的笔算｝（第｛1｝课时）
时间：｛2026年11月4日｝
研究主题：｛｝

【人员】
中心发言人：｛｝
蹲点领导：｛｝
主持人：｛｝
参加教师：｛张一、王二、李三、赵四、陈五、徐六、杨七、周八｝
教师侧重：｛｝
教研组：｛四年级数学备课组｝
教研组长：｛｝
教研组长补充：｛｝

【输出】
输出目录：｛D:\教研\2026秋\集体备课｝
要的材料：｛总表 + 附件 + 教研活动记录｝
```

各项不填时的默认：

| 项 | 留空时 |
|---|---|
| 时间 | 用当天日期 |
| 研究主题 | 按教材内容自动拟，≤30 字 |
| 中心发言人 | 从参加教师里随机指定一人（不会等于蹲点领导） |
| 蹲点领导 | 该格留空，不编造 |
| 主持人 | 默认＝中心发言人 |
| 教师侧重 | 自动按 8 类教学侧重分配，保证每人不同 |
| 教研组长 | 只用于确认「常规检查整改要求」出自谁，正文不出现姓名 |
| 教研组长补充 | 当作没有这回事：记录里不设这一节、不提组长补充、不编内容 |
| 教研组 | 「{年级}{学科}备课组」 |
| 参加人员栏 | **自动写全名单**（姓名顿号分隔），想额外带上领导就在 prompt 里单说一句 |
| 要的材料 | 三样全出，附件**默认合成一份**（每人一页） |

> 《教研活动记录》的正文一律写成**专业、结构化的条目**（六节：教材解读／目标与重难点／环节与活动设计／形成的共识／常规检查整改要求／蹲点领导意见），**不写「某某：……」式的人物发言**。这条是固定写法，不用在 prompt 里额外说明。
>
> **只写了单元、没写课时 → 按整个单元做单元整体教研**。教材内容就写「第X单元 ×××」，不用补「第几课时」。要落到某一课时，得明确写出来（如「第X单元 ×××（第1课时）」）。
>
> **版式不许提要求**：输出文件沿用上级模板，只填 `{{占位符}}`。prompt 里不用写「调整格式」「美化一下」「加一行」，写了也不会照做——模板的格式、结构、字体、页面设置一律不动。模板本身要改（加行、改栏目名），先改模板源文件，再用 `--tpl-main/--tpl-att` 指过来重跑。
