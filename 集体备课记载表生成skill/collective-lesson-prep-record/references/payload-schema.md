# payload 结构

生成时把内容写成一份 JSON，交给 `scripts/run.py`。**键名就是模板里的占位符名**，中文键优先；也接受少量英文别名（见表末）。

## 结构

```jsonc
{
  "学科": "数学",
  "年级": "四年级",
  "时间": "2026年11月4日",
  "教材内容": "第四单元 三位数乘两位数的笔算",
  "研究主题": "借迁移类推理解三位数乘两位数的算理，发展运算能力",
  "中心发言人": "王二",
  "蹲点领导": "刘老师",          // 未提供就写 ""，会留空
  "参加人员": "张一、王二、李三、赵四",
  "教研组长": "刘组长",           // 可选，只在记录里署名用
  "教研组长补充": "",             // 可选上下文：组长口头补充、外校做法。留空＝没有这回事，记录里一个字都不提，脚本也不补
  "总表": {
    "教材解读": "……",           // 段落之间用 \n
    "教学目标": "1. ……\n2. ……\n3. ……",
    "教学重难点": "重点：……\n难点：……",
    "中心发言人发言内容": "……\n……",
    "备课组成员发言": "张一：……\n王二：……\n（每人一行，人数＝参加教师数）",
    "领导发言提要": "……\n……"
  },
  "附件": [
    { "教师姓名": "张一", "教学目标": "……", "教学重难点": "……", "教学设计": "……", "学生活动": "……" }
  ],
  "教研活动记录": {
    "活动主题": "四年级数学备课组第十周集体备课活动",
    "活动时间": "2026年11月4日",
    "主持人": "王二",
    "教研主题": "……",
    "参加人员": "张一、王二、李三、赵四",   // 可选，默认与总表一致（全名单）
    "教研内容": "一、教材解读\n王二：……\n\n……"
  }
}
```

- `附件` 数组的顺序就是输出顺序；`学科/年级/时间/教材内容/研究主题` 五项在附件里自动从顶层复制，**不必重复写**。
- `教研活动记录` 里的 `活动时间/主持人/教研主题/参加人员` 省略时，自动取顶层的 `时间/中心发言人/研究主题/参加人员`。
- `教研组长补充` 只是写作用素材：**给了**就吸收进记录的「教研内容」（在「领导意见」之前单立一节，`组长姓名：……` 口吻）；**没给**就当作没有这回事——不设这一节、不提组长补充、不编发言，脚本也不会替你补。
- 多行内容一律用 `\n`（JSON 里的转义写法），不要用 `\\n` 字面量，也不要留空行。
- 内容里**不要出现半角花括号 `{` `}`**，脚本按 `{{ }}` 识别占位符，混进去会误判。

## 字段别名（接受，但推荐用中文键）

| 中文键 | 可用别名 |
|---|---|
| 学科 | subject |
| 年级 | grade |
| 时间 | date |
| 教材内容 | textbook、content |
| 研究主题 | topic |
| 中心发言人 | speaker |
| 蹲点领导 | supervisor |
| 参加人员 | participants |
| 附件 | teachers |
| 教师姓名 | 姓名、name |
| 总表 | main |
