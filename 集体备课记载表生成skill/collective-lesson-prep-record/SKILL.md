# 集体备课记载表 · 一键出稿

## 你的工作方式

你是备课组里负责整理材料的那个人。组里刚开完一次集体备课，桌上摆着两份空白模板：一份总表、一份附件。你要做三件事——

1. 把总表 13 个格子填满（教材解读、目标、重难点、中心发言人发言、成员发言、领导提要）；
2. 按参加教师名单，**一人一份**《备课组成员教学重构》，内容各写各的、不许只换名字；
3. 再写一份《教研活动记录》，用**参研教师当场边听边记**的口吻，把谁说了什么记下来。

填表脚本只替换 `{{占位符}}`，表格骨架、字体、页面设置、原有文字一律不动。**不要手工改模板。**

> 学科不限：语文、数学、英语、科学、道法、音体美、信息科技都走这一套，目标写成该学科课标的核心素养表述即可（词表见 `references/field-spec.md`）。

### 红线（破一条就重做）

1. **模板格式不动**：只允许替换占位符文字。不增删行列、不改合并单元格、不改字体字号、不改页边距。
2. **人名、时间、人数一律不编造**。用户没给的按下方默认规则处理，不许自己圆。
3. **中心发言人 ≠ 蹲点领导**，两个格子填的不是同一个人。
4. **每位参加教师一份附件**，名单 8 人就 8 份，一个不能少、顺序按名单、内容必须有差异。
5. **教材内容从简**：写「第X单元 具体内容」，不写教材版本、册次、第几课时。
6. **教研活动记录只记事实**：谁说了什么、形成了什么意见。不写反思、心得、收获、启示。
7. 拿不准的（课时内容、教师名单）先问，别猜着往下写。
8. **参加人员一栏写全名单**：名单上有几个人就写几个名字，顿号分隔；不要写「XX组教师」这种概括。蹲点领导有自己的格子，不在这一栏重复。

## Phase 0 收集信息

把用户给的信息对到这张表上，**缺什么一次问完**（最多 4 个问题），已经给的不重复问。

| 字段 | 必填 | 用户没给怎么办 |
|---|---|---|
| 学科 | 是 | 能从教材内容/资料推断的，说明依据并请确认；推不出就问 |
| 年级 | 是 | 同上（写「四年级」这种，不写「4年级」） |
| 教材内容 | 是 | 用户给课时、教材照片、教案、教参都行；只说「第X单元」时按单元核心课时处理并说明 |
| 时间 | 否 | **用系统当天日期**（`date +%Y年%-m月%-d日` 取，不要自己算），并告知用户可改 |
| 研究主题 | 否 | 围绕本课核心素养自动拟定，一句话、≤30 字 |
| 中心发言人 | 否 | 从参加教师名单里随机指定 1 人（不得等于蹲点领导），填姓名 |
| 蹲点领导 | 否 | 该项**留空**，不编造；如用户要留空就留空 |
| 主持人 | 否 | 默认＝中心发言人 |
| 参加教师 | 是 | 附件按名单逐人生成；没给就只出总表+记录，并提醒补名单才能出附件 |
| 教师侧重 | 否 | 不给就按 `references/field-spec.md` 的 8 类教学侧重自动分配，保证每人不同 |
| 教研组长 | 否 | 姓名，只用于在记录里署名；不给就写「教研组长」 |
| 教研组长补充 | 否 | **纯上下文素材，不进任何表格**。组长口头补充、转述外校做法/经验写这里，只在《教研活动记录》里体现；**不给就当作没有这回事，记录里一个字都不提、也不要编** |
| 参加人员栏 | 否 | **写全名单**：把参加教师姓名全部列出、顿号分隔，如「张一、王二、李三、赵四」；不用「XX组教师」概括，脚本也会自动按名单补全 |
| 输出目录 | 是 | **必须问**，不要默认扔在技能目录里；用户说「放桌面/放教研文件夹」就按他说的 |

**标准化提示词**（用户每次照这个填，`｛｝` 里换成自己的内容即可，完整版见 `references/prompt-template.md`）：

```text
用 collective-lesson-prep-record 生成集体备课材料。

学科：｛数学｝　年级：｛四年级｝
教材内容：｛第四单元 三位数乘两位数的笔算｝（第｛1｝课时）
时间：｛2026年11月4日｝
研究主题：｛｝
中心发言人：｛｝　蹲点领导：｛｝　主持人：｛｝
参加教师：｛张一、王二、李三、赵四、陈五、徐六、杨七、周八｝
教师侧重：｛｝
教研组：｛四年级数学备课组｝
输出到：｛D:\教研\集体备课\2026秋\｝
只要：｛总表 + 附件 + 教研活动记录｝
```

用户直接甩教材照片、教案、教参文档过来也算给了「教材内容」，照资料写，不要凭印象编教材页码。

## Phase 1 读资料

有教案/教材照片/教参就先读，按这份清单摘，摘不全后面必然写空：

| 要素 | 用到哪 |
|---|---|
| 单元位置、前后知识衔接 | 教材解读 |
| 例题、习题呈现方式 | 教材解读、教学设计 |
| 本课要落实的核心素养 | 教学目标（总表＋附件） |
| 关键问题、学生易错点 | 重难点、成员发言 |
| 教学环节与活动形式 | 教学设计、学生活动 |

资料打架时的优先级：**教材/教参 > 教案 > 课件 > 练习册**。

## Phase 2 写内容

动笔前读 `references/field-spec.md`（逐字段字数与写法、学科素养词表、教师侧重池）。

三条最容易被扣分的：

1. **换行就是排版**。payload 里用 `\n` 断行，脚本会转成 Word 里的换行符：教学目标一条一行、重难点「重点：」「难点：」各一行、教学设计按环节一行、成员发言每人一行、教研内容按「一、二、三」分段。
2. **成员发言必须覆盖全部参加教师**，每人一条、以「姓名：」开头，观点要具体到可操作（用哪个情境、设计哪道变式、抓哪个错例），不写「要认真备课」这类空话。中心发言人也要在这里发言，但与「中心发言人发言内容」角度错开（那里讲主线，这里补一个具体建议）。蹲点领导**不出现在**成员发言里。
3. **八份附件要真的不一样**：同课异构的角度差异要落在教学环节和活动设计上，不能只换导入情境。

教研活动记录（第三份产出）：

- 口吻＝**坐在下面听记的老师**：按会议推进顺序记，`姓名：说了什么` ，夹杂「大家讨论认为……」。
- 结构建议：一、教材解读 → 二、目标与重难点 → 三、环节与活动讨论 → 四、形成的共识 → 五、领导意见。
- 只记事实与结论；**不写**反思、收获、启示、下一步打算。
- 篇幅 600–1000 字，要点式，不写成散文。
- **给了「教研组长补充」时**（组长随口补的话、别校的做法/经验），把它当作写作素材写进记录：放在「领导意见」之前单立一节（如「五、教研组长补充」，后面的领导意见顺延编号），记成 `组长姓名：……` 的口吻，转述外校做法时照实写「某某学校的做法是……」，不加评价、不写成反思。这段是**上下文素材不是模板字段**，只在记录里出现，总表一格都不填。
- **没给「教研组长补充」就一句都不要写**：不立这一节、不提「组长补充」、不臆造组长发言。脚本也不会替你补——缺了就是没有这回事。

## Phase 3 落盘出文件

payload 结构见 `references/payload-schema.md`（有完整示例，照着改）。写成 `payload.json` 放当前工作目录，别放教研文件夹里。

```bash
python "<skill目录>/scripts/run.py" \
  --payload payload.json \
  --out "用户指定的输出目录" \
  --merged
```

- `--merged` 额外出一份《备课组成员教学重构-汇编.docx》，每人一页，方便一次打印；不要就省掉这个参数。
- 只重出某一部分：`--only main` / `--only attachments` / `--only record`。
- 只想校验 payload 有没有漏字段：`--check`（不写文件）。
- 附件标题默认标上教师姓名（模板没有 `{{教师姓名}}` 占位符，靠标题区分；`（张一）` 这样加在「备课组成员教学重构」后面）。**要严格保持标题原样**就加 `--no-name-in-title`。
- 用户自己的模板版本更新过：加 `--tpl-main "路径"` / `--tpl-att "路径"`，占位符名必须仍是 `{{...}}`。
- 脚本自带比对：除 `word/document.xml` 外所有包内部件逐字节一致，表格/行/单元格/列宽/页面设置数量不变，无残留占位符。**出现 ✗ 就不要交付**，先查 payload。

输出文件：

```
集体备课记载表-总表-{教材内容}.docx
附件-教学重构/备课组成员教学重构-{姓名}.docx   ← 每人一份
备课组成员教学重构-汇编.docx                  ← 加 --merged 才有
教研活动记录-{教材内容}.docx
```

## Phase 4 交付

1. `present_files` 打开**总表**和**教研活动记录**（最常被检查的两份），附件在子目录里说明位置。
2. 回复里给一张核对清单，短、可扫：

   ```
   总表 13 格 ✓   附件 8 份（张一…周八）✓   教研活动记录 ✓
   中心发言人：张一    蹲点领导：李主任    时间：2026年11月4日
   ```
3. 交付说明写三句话就够：
   - **哪些是资料里有的**（教材解读、例题、环节），**哪些是按常规补的**（成员发言的具体做法、领导提要角度），请组里过一遍；
   - 附件标题已按姓名标注，若要保持模板原标题用 `--no-name-in-title` 重跑；
   - 要改某一位老师的附件内容 / 换中心发言人 / 加人减人，说一声就重跑，不用重填整份。

## 常见追问怎么接

| 用户说 | 怎么做 |
|---|---|
| 「只要总表」 | `--only main`，不生成附件与记录 |
| 「附件合成一份」 | `--merged`，或直接给汇编本 |
| 「9 个老师」 | 名单里加人，附件自动多一份；教师侧重不够就自己按学科特点再分 |
| 「换个中心发言人」 | 只改 payload 的 `中心发言人` 和 `备课组成员发言`，重跑 |
| 「课时内容不对」 | 先看 payload 的 `教材内容`，再改总表/附件的正文，别动模板 |
| 「我们模板改了」 | 用 `--tpl-main/--tpl-att` 指新模板；占位符被改名了要同步改 payload 的键 |
