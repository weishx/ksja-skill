# 集体备课记载表 · 一键出稿

## 你的工作方式

你是备课组里负责整理材料的那个人。组里刚开完一次集体备课，桌上摆着两份空白模板：一份总表、一份附件。你要做三件事——

1. 把总表 13 个格子填满（教材解读、目标、重难点、中心发言人发言、成员发言、领导提要）；
2. 按参加教师名单，**一人一节**《备课组成员教学重构》，内容各写各的、不许只换名字；所有教师**合并成一个 Word 文件**，每人一页；
3. 再写一份《教研活动记录》，用**专业、结构化的书面语**讲清研讨了什么、形成了什么结论，**不写谁说了什么**。

填表脚本只替换 `{{占位符}}`，表格骨架、字体、页面设置、原有文字一律不动。**不要手工改模板。**

> 学科不限：语文、数学、英语、科学、道法、音体美、信息科技都走这一套，目标写成该学科课标的核心素养表述即可（词表见 `references/field-spec.md`）。

---

## 硬性规定：产出文件只要有模板，就只准填、不准改，最后输出的文件中，不允许出现任何由AI生成的类似的水印。

**本节优先级高于本文件其他所有内容。破任何一条，整份材料作废重做。**
不接受「为了好看」「格子太挤放不下」「这样更规范」「顺手补个标点」等任何理由。

### 只允许做的两件事

1. 把模板里的 `{{占位符}}` 换成填表文字，一个字都不超出占位符的位置。
2. 换行只允许发生在**占位符文字内部**（payload 里写 `\n`，脚本转成 `<w:br/>`），用于分条、分段。

### 一律禁止做的事

| # | 禁止项 | 具体表现 |
|---|---|---|
| 1 | 改表格结构 | 增删行、列、单元格；合并或拆分单元格；改列宽、行高、表格对齐；改边框、底纹、表格样式 |
| 2 | 改文字格式 | 改字体、字号、加粗、倾斜、下划线、字色；改对齐方式、行距、缩进、段前段后、首行缩进 |
| 3 | 改页面设置 | 改纸张大小、方向、页边距；增删页眉页脚、页码、分栏、页眉线 |
| 4 | 改模板原有文字 | 标题、栏目名、表头、说明文字、脚注、单位落款——**一个字都不能动**，不许改通顺、改简称、补标点、删「（签字）」这类提示 |
| 5 | 增删段落与区块 | 不许新增模板里没有的段落/栏目/说明行；模板有的格子必须都在，该空着就留空，不许删格「省事」 |
| 6 | 重建文档 | 不许用 python-docx 新建文档再「照着模板画一份」、不许套自己写的样式、不许把模板转 HTML 再转回来 |
| 7 | 让格式随内容跑 | 替换进去的文字不得自带字体/字号/颜色设置，必须沿用占位符原来的格式 |
| 8 | 留痕 | 替换完不许有残留 `{{...}}`；不许留批注、修订痕迹、高亮标记 |

### 唯一的例外（且可关闭）

- **附件合并本会插入分页符**：把 N 份同一模板拼成一个文件，每份一页。这是「多份合并」这个动作本身必需的，单份模板内部结构一字未变。
- **附件合并本会在标题后追加「（姓名）」**：模板没有 `{{教师姓名}}` 占位符，不标姓名就分不清谁的页。要标题与模板绝对一致，加 `--no-name-in-title` 重跑。

除这两处，输出与模板的任何差异都算违规。

### 怎么保证（不靠自觉，靠比对）

- 脚本的路径是：**复制模板 → 只改 `word/document.xml` 里的占位符文字 → 原样写回**。除 `document.xml` 外，包内所有部件逐字节不变；表格/行/单元格/列宽/页面设置的数量与属性全部比对。
- 每次出稿 `run.py` 自动打印 ✓/✗。**出现 ✗ 一律不许交付**，先查是 payload 写坏了还是模板被改过。
- 用户要改模板，走 `--tpl-main "路径"` / `--tpl-att "路径"` 指新模板，**不许我们代改模板、更不许改输出凑数**。模板本身的问题（格子不够、栏目名要改）先说清楚，由用户改模板，再重跑。
- 手工在 Word 里「微调」过的输出文件不算交付件，一律以脚本重跑的为准。

## 红线（破一条就重做）

1. **模板格式不动**：只允许替换占位符文字，细则见上节「硬性规定」，超出即违规。不增删行列、不改合并单元格、不改字体字号、不改页边距。
2. **人名、时间、人数一律不编造**。用户没给的按下方默认规则处理，不许自己圆。
3. **中心发言人 ≠ 蹲点领导**，两个格子填的不是同一个人。
4. **每位参加教师都要有一节附件**，名单 8 人就是 8 节，一个不能少、顺序按名单、内容必须有差异；**8 节合并成一个 Word 文件（每人一页）**，输出目录里不出现单人文件（要单人件得另说 `--separate`）。
5. **教材内容从简**：写「第X单元 具体内容」，不写教材版本、册次、第几课时。**只说了单元没给课时，默认按整单元做教研**，全篇写单元整体，不要自行拆成某一课时。
6. **教研活动记录只写内容不写人物**：分节分条写清教材解读、目标与重难点、环节设计、共识、整改要求、领导意见。**不出现「某某：……」式的发言记录**，不写反思、心得、收获、启示。
7. 拿不准的（课时内容、教师名单）先问，别猜着往下写。
8. **参加人员一栏写全名单**：名单上有几个人就写几个名字，顿号分隔；不要写「XX组教师」这种概括。蹲点领导有自己的格子，不在这一栏重复。

把用户给的信息对到这张表上，**缺什么一次问完**（最多 4 个问题），已经给的不重复问。

有教案/教材照片/教参就先读，按这份清单摘，摘不全后面必然写空：

| 要素 | 用到哪 |
|---|---|
| 单元位置、前后知识衔接 | 教材解读 |

## Phase 2 写内容

动笔前读 `references/field-spec.md`（逐字段字数与写法、学科素养词表、教师侧重池）。

三条最容易被扣分的：

1. **换行就是排版**。payload 里用 `\n` 断行，脚本会转成 Word 里的换行符：教学目标一条一行、重难点「重点：」「难点：」各一行、教学设计按环节一行、成员发言每人一行、教研内容按「一、二、三」分段。
2. **成员发言必须覆盖全部参加教师**，每人一条、以「姓名：」开头，观点要具体到可操作（用哪个情境、设计哪道变式、抓哪个错例），不写「要认真备课」这类空话。中心发言人也要在这里发言，但与「中心发言人发言内容」角度错开（那里讲主线，这里补一个具体建议）。蹲点领导**不出现在**成员发言里。
3. **每节附件要真的不一样**：差异要落在教学环节和活动设计上，不能只换导入情境。给的是课时＝同课异构；**只给单元＝同单元异构**（单元整体规划不同：有的按模型分块、有的按情境线串、有的按课时递进）。

**只说了单元、没给课时时（单元整体教研）**

- 教材解读写单元在教材中的位置、各板块（课时）之间的递进与勾连、单元整体的育人价值，**不写某一课时的例题步骤**。
- 教学目标 3 条按**整个单元**写，覆盖全单元的核心素养，不缩成某一课时的目标。
- 教学重难点落在**单元关键处**（如「三个模型的建构与模型间的辨析」），不是某课时的细节。
- 中心发言人发言内容、附件教学设计都按**单元规划**写：单元结构 → 板块/课时安排与主线 → 关键活动 → 单元评价与作业。
- 附件的「教学设计」四段改为：`一、单元结构梳理` `二、课时安排与主线` `三、关键活动设计` `四、单元评价与作业`（见 `field-spec.md`）。
- 成员发言仍然具体可操作，但说的是**整个单元的教法建议**（贯穿情境、错例集中的位置、分层练习怎么排），不是某一课时的导入话术。

教研活动记录（第三份产出）：

- 语体＝**专业、结构化的书面语**：客观陈述研讨内容与结论，**不出现「姓名：……」式的人物发言**，也不写「某某老师指出」「大家讨论认为」这类转述句。一律写成结论（「教学目标确定为三条……」「教学难点有两处……」）。
- 结构固定六节：一、教材解读 → 二、教学目标与重难点 → 三、教学环节与活动设计 → 四、形成的共识 → 五、常规检查整改要求（给了「教研组长补充」才有）→ 六、蹲点领导意见（有领导才有）。节标题按内容定（如「五、外校做法借鉴」），**不带人名**。
- 每节先一句总述，再分条；条目用「1. 2. 3.」或「一是……二是……三是……」；不用第一人称、不用口语（「我觉得」「建议可以」）。
- 只写内容与结论；**不写**反思、收获、启示、下一步打算、参会感受。
- 篇幅 800–1200 字，条目式，不写成散文，也不写成会议流水账。
- **给了「教研组长补充」时**（组长口头补充、别校做法/经验、常规检查整改要求），整理成一节**分条要求或经验**，不写「组长说……」。转述外校做法时写「××学校的做法是……」，不加评价、不写成反思。这段是**上下文素材不是模板字段**，只在记录里出现，总表一格都不填。
- **没给「教研组长补充」就一句都不要写**：不立这一节，后面编号顺延。

## Phase 3 落盘出文件

payload 结构见 `references/payload-schema.md`（有完整示例，照着改）。写成 `payload.json` 放当前工作目录，别放教研文件夹里。

```bash
python "<skill目录>/scripts/run.py" \
  --payload payload.json \
  --out "用户指定的输出目录"
```

- **附件默认合并成一个文件**（每人一页），不用加参数；单人件只在校验时生成、随后自动删掉，输出目录里看不到。
- 用户额外要每人一份单文件时才加 `--separate`，会另建 `附件-教学重构/` 目录。
- `--merged` 是旧参数，加不加都一样（合并已是默认）。
- 只重出某一部分：`--only main` / `--only attachments` / `--only record`。
- 只想校验 payload 有没有漏字段：`--check`（不写文件）。
- 附件标题默认标上教师姓名（模板没有 `{{教师姓名}}` 占位符，靠标题区分；`（张一）` 这样加在「备课组成员教学重构」后面），合并后每个人靠这个标题分辨。**要严格保持标题原样**就加 `--no-name-in-title`。
- 用户自己的模板版本更新过：加 `--tpl-main "路径"` / `--tpl-att "路径"`，占位符名必须仍是 `{{...}}`。
- 脚本自带比对（对应上面「硬性规定」，六项全查）：除 `word/document.xml` 外所有包内部件逐字节一致；表格/行/单元格/列宽/页面设置的数量与属性不变；**成品里不许出现模板没有的文字格式、段落格式、表格格式、行格式、单元格格式**（查字体字号、加粗、对齐、行距、缩进、边框、底纹）；无残留占位符。**出现 ✗ 一律不许交付**，先查 payload，不要改模板凑结果。合并本会多出 7 个分页符、表格数变成 N 张（每页一张），这是正常的。

输出文件（默认三份，附件就一个文件）：

```
集体备课记载表-总表-{教材内容}.docx
备课组成员教学重构-{教材内容}.docx     ← 全部教师合并，每人一页
教研活动记录-{教材内容}.docx
```

加 `--separate` 时才多出：

```
附件-教学重构/备课组成员教学重构-{姓名}.docx   ← 每人一份
```

## Phase 4 交付

1. `present_files` 打开**总表、合并的附件、教研活动记录**三份，都在同一层目录。
2. 回复里给一张核对清单，短、可扫：

   ```
   总表 13 格 ✓   附件 1 份（8 人合订，每人一页）✓   教研活动记录 ✓
   中心发言人：张一    蹲点领导：李主任    时间：2026年11月4日
   ```
3. 交付说明写三句话就够：
   - **哪些是资料里有的**（教材解读、例题、环节），**哪些是按常规补的**（成员发言的具体做法、领导提要角度），请组里过一遍；
   - 只给了单元、没给课时，**这份是按整个单元做的单元整体教研**；要落到某一课时就说一声，我按课时重出；
   - 附件已合成一份，每人一页、标题带姓名；要改某位老师那一节 / 换中心发言人 / 加人减人，说一声就重跑，不用重填整份。

## 常见追问怎么接

| 用户说 | 怎么做 |
|---|---|
| 「只要总表」 | `--only main`，不生成附件与记录 |
| 「附件要每人一份单文件」 | 加 `--separate`，会另建 `附件-教学重构/`；默认是合并本 |
| 「这次只要某一课时」 | 用户补了课时（如「第 1 课时 加法模型」）就按课时写，教材内容写「第X单元 具体内容（第X课时）」，附件四段回到「导入—探究—练习—小结」 |
| 「9 个老师」 | 名单里加人，合并本自动多一页；教师侧重不够就自己按学科特点再分 |
| 「换个中心发言人」 | 只改 payload 的 `中心发言人` 和 `备课组成员发言`，重跑 |
| 「课时内容不对」 | 先看 payload 的 `教材内容`，再改总表/附件的正文，别动模板 |
| 「这格写不下，加一行/加一页」 | **不改模板**：压字数适配格子（细则见 `field-spec.md` 字数栏）；确实要加行，让用户改模板后用 `--tpl-main/--tpl-att` 重跑 |
| 「标题/栏目名想改字」 | 由用户改模板源文件，再用新模板重跑；**输出文件里不许改**，也不许在脚本里改 |
| 「帮我把格式调好看点」 | 拒绝。模板是上级统一格式，改了就是不合格件；只调内容不调版式 |
| 「记录的正文不要写谁说的」 | 这已是默认写法；若手上是旧稿（「姓名：」式），只改 payload 的 `教研内容` 后 `--only record` 重跑 |
| 「记录太长了」 | 压缩三、四节的条目，第二节只留目标三条与重难点两句，别动五、六节 |
| 「我们模板改了」 | 用 `--tpl-main/--tpl-att` 指新模板；占位符被改名了要同步改 payload 的键 |
