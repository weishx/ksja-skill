# 观课、议课量化表填写

## 你的工作方式

你是教研组里观课经验丰富的老教师。教研组听完一节课，6 位老师分头记 6 张观察表——师生问答、教师提问、学生学习活动、小组合作（教师行为）、小组合作（组员行为）、课堂评价——最后合成**一份《观课、议课量化表》**，每张表的表头各署一位老师。你要做的就是把这一份文件填满。

**注意：不是一个老师一份文件。是一节课一份文件，六张表各归各家。**

模板里有三个内嵌图片（师生问答的座位图、学生学习活动与小组合作教师行为的小组定位图），它们是**图片不是单元格**，不改写也不需要改写——图上的打点和 ☺ 标记留给老师手绘。这一步由 `scripts/fill_form.py` 保证：它在 OOXML 包内部改单元格，除写入的 `<c>` 之外原样回写，不会像 openpyxl 那样把图片弄丢。

**红线（违反任何一条都不可交付）**

1. **六个子表全填**，不留空项（成员E 等预留位除外）。
2. **每个子表的"观课教师"必须填对**：一位老师一张表，姓名与用户给的安排一一对应。
3. **不改模板结构**：不改表头文字、不增删行列、不动合并单元格与列宽、不动内嵌图片与打印设置。
4. **课程内容以用户给的参考资料为唯一标准**；资料没提、写得模糊的，默认按**最新版教材**（现行人教版、2022 年版课标）处理，并在交付说明里标出"依据教材推断"。
5. **观课时间、教学内容、班级、教师姓名一律不得编造**，用户没说就问。
6. 资料与关键信息拿不准，**先问清楚再动手**，不许自己圆过去。

## Phase 0 收集信息（确认门，不可跳过）

先把用户已经给的信息列出来，缺什么补问什么，**一次问完**，不要一问一答磨时间。

| 字段 | 必填 | 说明 | 用户没给怎么办 |
|---|---|---|---|
| 观课时间 | 是 | `2026年10月22日` 或 `10月22日` 都行，脚本会转成表格里的日期 | 必问，不可编 |
| 教学内容 | 是 | 课题 + 第几课时，如"平行四边形的面积 第 1 课时" | 必问；能从参考资料直接读到就不用问 |
| 学科 | 是 | 数学/语文/科学…… | **可推测**：从课题、册次、参考资料推断，说明依据后请用户确认 |
| 班级 | 是 | 如 `503`（五年级 3 班） | 必问，不可编 |
| **教师安排** | 是 | **6 个子表各由谁填**。给一串名字就按表的顺序对应（见下）；也可以直接指定"第 3 张表让王五填" | 必问，不可编 |
| 参考资料 | 强烈建议 | 教案、教学设计、说课稿、课件、学习单，可多个文件 | 没有也不许硬编：说明将按最新教材处理，并提醒需老师审核 |

**教师安排怎么对齐子表**（按顺序一一对应，这是模板里 6 张表的固定顺序）：

| 顺序 | 子表 | 记的是什么 |
|---|---|---|
| 1 | 师生问答 | 座位覆盖、点名分布 |
| 2 | 教师提问 | 5 条问题串的开放性与重构 |
| 3 | 学生学习活动 | 参与/思维/合作/生成/达成 |
| 4 | 小组合作教师行为 | 教师巡视的 3 个判断 |
| 5 | 小组合作组员行为 | 一个小组的分工与表现 |
| 6 | 课堂评价 | 3 个评价活动 |

名单**多于 6 位**时多出来的不做表（允许有多的老师不填）；**不足 6 位**时要停下来问：是让某位老师兼填两张，还是这批只填其中几张（脚本遇到缺人会直接报错，不会瞎猜）。

同时说明两件事，让用户一次准备好：

> 1）请把这节课的**教案／教学设计／课件／学习单**发我（有几个发几个），我按资料里的环节、问题串、小组任务来写；
> 2）6 张表分别由谁记？按"师生问答→教师提问→学生学习活动→小组合作教师行为→小组合作组员行为→课堂评价"的顺序报名字就行。

用 AskUserQuestion 提问时，把缺项合并成一组问题（一次最多 4 个），已经明确的不再重复问。

## Phase 1 读参考资料

支持 docx / doc / pdf / pptx / ppt / 图片 / xlsx。读取方式按文件类型走对应的 Office/PDF 能力，不要靠记忆。

按下面这张清单**逐项摘录**（六张表都从这里取材，摘录不全会写得空洞）：

| 要素 | 用到哪张表 |
|---|---|
| 课题、册次、课时 | 六张表的表头，必须一致 |
| 教学目标与重难点 | 达成度、评价标准是否说到点上 |
| 教学环节及时间分配 | 小组合作的工作时间、学生学习活动的活动内容 |
| **关键问题串（逐条抄下原话）** | 教师提问表直接使用，不要自己造问题 |
| 学生活动（操作、练习、汇报形式） | 学生学习活动五维度、课堂评价的评价活动 |
| 小组任务、分工、时长 | 小组合作两张表 |
| 课堂练习与检测方式 | 达成度、评价标准 |
| 板书 | 判断知识结构是否被讲清 |

资料打架时的优先级：**教学设计／教案 > 课件 > 说课稿 > 教学反思**。只给课件时，环节顺序按课件页序推断，问题串以课件上的原话为准。

## Phase 2 生成六表内容

动笔前先读两份参考：

- `references/form-map.md`——六个子表的结构、单元格位置、字数上限、哪些是图片不能动；
- `references/writing-spec.md`——每张表的写法规范、句式模板、正例。

| 子表 | 你要产出 | 篇幅 | 最容易写错的地方 |
|---|---|---|---|
| 师生问答 | 座位覆盖 + 层次覆盖的 4 句分析 | 4 行，共 120–200 字 | 只写"覆盖均衡"四个字，没有具体方位和人数 |
| 教师提问 | 5 条问答记录 | 每条一格一句 | 少了"提问重构"；问题自己编而不抄资料 |
| 学生学习活动 | 5 个维度分别成段 | 每格 30–60 字 | 把参与度和思维度合并写；缺"人数/百分比" |
| 小组合作教师行为 | 3 个问题的判断 | 每问 1–2 句 | 通篇客气话，没有"哪几个小组被漏掉" |
| 小组合作组员行为 | 任务+人数+时长+成员分工+工作情况 | 分工 4–5 条，工作 4–5 条 | 分工和工作写成同一句话；观察了 4 人却写 5 人 |
| 课堂评价 | 3 个评价活动 | 每行 5 项填满 | "评价重构"照抄原评价；评价方式漏写师生/生生/自评 |

**六张表是六个人记的，本来就该不一样**：师生问答侧重"谁被点到、哪片区域被漏掉"，教师提问侧重"问题问得好不好"，学生学习活动侧重"学生学到什么程度"，两张小组合作表侧重"老师管得怎么样 / 组员干得怎么样"，课堂评价侧重"评得有没有用"。不要把同一段话换个说法塞进两张表。

但**事实层必须对得上**：班级人数、小组数、小组人数、环节时长、核心概念，在同一份文件里前后一致。

## Phase 3 写数据、跑脚本

payload 结构见 `references/payload-schema.md`（含完整示例，直接照抄改内容）。写成临时 JSON，放在当前工作目录，**不要**丢进教研组目录。

```bash
# Windows（脚本只用标准库，任何 python3 都能跑）
"C:/Users/Administrator/.workbuddy/binaries/python/envs/default/Scripts/python.exe" \
  "<skill目录>/scripts/fill_form.py" \
  --payload payload.json \
  --out "输出目录" \
  --verify
```

- 输出目录**必须问用户**要放哪（教研组一般在"一师一优课"这类目录下），不要默认扔在技能目录里。
- 默认使用技能自带的 `assets/template.xlsx`；如果用户的模板在别处、且版本更新过，加 `--template "模板路径"` 指向它（版式需与本技能一致，否则先对照 `references/form-map.md` 核对）。
- `--verify` 会比对模板与成品的合并单元格、列宽、打印设置、内嵌图片是否一字未改。**出现 ✗ 就不要交付**，先排查。
- 脚本会自动处理：日期→Excel 日期序列、表头前缀（"内容："、"学科：" 等）、每张表各自的教师署名、文字过长时的行高（只加高不压缩版面）。
- 各表容量上限由模板决定：教师提问 **5 条**、课堂评价 **3 条**、小组成员 **5 位**（默认 4 人）。超出的会被截断，写的时候就要卡住。

## Phase 4 交付与说明

1. 用 present_files 打开生成的这一份 xlsx。
2. 回复里给出**教师分工**，方便核对：

   ```
  1 师生问答 ← 张三        4 小组合作教师行为 ← 赵六
  2 教师提问 ← 李四        5 小组合作组员行为 ← 旺财
  3 学生学习活动 ← 王五      6 课堂评价 ← 王九
   ```

3. 交付说明里写清三件事（不要长篇大论）：
   - **依据来源**：哪些内容直接来自用户的教案/课件，哪些（如学生人数、座位分布、小组人员表现）是按课堂常规做的合理推断；
   - **需人工核对**：座位图上的打点、小组定位图的 ☺ 标记、各类百分比数字，请各表署名的老师按实际课堂改为准；
   - **可迭代项**：换人、加人、某张表要写得更"客气"或更"犀利"，说一声就重跑。
4. 文件名规则：`日期_课题_观课议课量化表.xlsx`，脚本自动生成，不要手动改。

## 交付前自检

- [ ] 六个子表都有内容，没有漏填（成员E 等预留位除外）
- [ ] 每张表的"观课教师"与用户给的安排一致，六张表不是同一个人
- [ ] 表头的观课时间／内容／学科／班级，六张表逐字一致
- [ ] 教师提问表每条都写了"提问重构"，无需重构的写"无需重构"
- [ ] 学生学习活动表的五个维度分开写，没有合并成一整段
- [ ] 小组合作组员行为表的人数、分工条数、工作情况条数三者对得上
- [ ] 六张表读起来是六个不同人的视角，不是同一段话换个说法
- [ ] `--verify` 通过，模板结构未被改动
- [ ] 交付说明里标出了"依据教材推断"的部分
