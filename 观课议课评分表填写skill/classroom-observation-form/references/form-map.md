# 模板结构图（观课、议课量化表.xlsx）

模板：`assets/template.xlsx`（6 个子表，与教研组现用模板一致）。
**所有位置都由 `scripts/fill_form.py` 里的 `SHEETS` 常量定义**；模板若改版，改那张表即可，不要改脚本其它部分。

通用规则：

- 只能写**合并区域的左上角单元格**，写到被合并掉的格子里内容会丢失。
- 三个内嵌图片（座位图 / 小组定位图）**是图片不是表格**，脚本完全不碰；图上的打点、☺ 标记由老师手绘。
- 行高会在文字超出时自动加高（只加不减，上限 430 磅）；列宽、合并、打印设置、页边距一律不动。

**每个子表都有自己的"观课教师"栏，填的是不同的人**（一节课一份文件，六张表六位老师）：

| 子表 | 观课教师所在单元格 | 备注 |
|---|---|---|
| 师生问答 | **J2** | 前面 I2 是标签"  观课教师："，只写 J2 |
| 教师提问 | **F2** | 整格写"观课教师：姓名" |
| 学生学习活动 | **F2** | 同上 |
| 小组合作教师行为 | **F3**（注意是第 3 行） | 同上 |
| 小组合作组员行为 | **F2** | 同上 |
| 课堂评价观察表 | **E2** | 与班级同格："班级：503   观课教师：姓名" |

## 子表 1　师生问答（`师生问答`）

| 位置 | 内容 | 说明 |
|---|---|---|
| B1:J1 | 标题"师生问答观察表" | 固定，不写 |
| B2 | `观课时间：X月X日` | 前缀+"X月X日"，整格一个字符串 |
| D2 / E2 | `内容：` / 课题 | D2 是标签，只写 E2 |
| F2 / G2 | `学科：` / 学科 | G2 写值 |
| H2 | `班级：503` | 标签与值同格 |
| I2 / J2 | `观课教师：` / 姓名 | J2 写值 |
| **B3:J23** | **座位图（内嵌图片）** | 不可写、不可改 |
| **B24:J28** | **覆盖分析（合并区）** | 4 行，每行一句，120–200 字 |

B24 固定写四层意思，一行一条：

```
覆盖是否均衡：……（点名覆盖面、共点到几人）
是否有"被忽视的座位区"：……（有/无 + 具体方位）
是否关注到不同层次的学生：……（学困生/中等生/优等生各几次）
提问是否集中在某几个学生身上：……（是否重复点名）
```

> 表格里没有"课程点评"这一栏，**不要**把 100 字课程点评塞进 B24。点评放在交付说明的对话里。

## 子表 2　教师提问有向、开放性（`教师提问`）

| 位置 | 内容 |
|---|---|
| A1:E1 | 标题，固定 |
| A2 | 标签 `观课时间：`，固定 |
| B2 | **日期**（Excel 日期序列，脚本自动转换） |
| C2 / D2 / E2 / F2 | `内容：…` `学科：…` `班级：…` `观课教师：…`（值与前缀同格） |
| A4:F6 | 表头，固定 |
| **A7:F11** | **数据区，只有 5 行** |

数据区 6 列：`A 序号` `B 问题` `C 提问对象（个别/集体）` `D 回答方式（个别/集体）` `E 提问是否有向、开放` `F 提问重构`。

- 序号写"问题一…问题五"（不写会自动补）。
- 5 行必须全满，**问题条数少于 5 时不要留空行**——留空会被清空，但表看起来就少了内容，所以宁可写满 5 条。
- 列宽参考：B 列约 11 字宽（每行约 5–6 个汉字，建议问题 ≤ 25 字）；C/D 约 8–16；E 约 25；F 约 14（重构句 ≤ 35 字）。

| 位置 | 内容 |

## 子表 4　小组合作学习期间教师行为（`小组合作教师行为`）

| 位置 | 内容 |
|---|---|
| A1:F1 | 标题，固定 |
| A3 | 标签 `观课时间：` |
| B3 | 日期序列 |
| C3 / D3 / E3 / F3 | `内容：…` `学科：…` `班级：…` `观课教师：…` |
| **A4:F16** | **小组定位图（内嵌图片，含 ☺ 标记）**，不可写；E5 的 ☺ 是手工标记，脚本不改 |
| **A18:F21** | **三个问题的判断（合并区）** |

A18 写三行，每条以"1、2、3、"开头，问题文字照模板抄，答案用 Tab 或空格分隔：

```
1、高效的引导者还是缺席的管理者？     ……（用一句半说明，要能指出具体在第几组、哪个环节）
2、更倾向于介入指导还是放手观察？     ……（说清放手多久、介入几次）
3、能均衡关注所有小组，还是固定关注某几个小组？     ……（8 个小组巡视了几个、哪几个停留不足）
```

## 子表 5　小组合作观察表（`小组合作组员行为`）

| 位置 | 内容 |
|---|---|
| A1:F1 | 标题，固定 |
| A2 / B2 | `观课时间：X月X日` / `内容：…`（标签与值同格） |
| D2 / E2 / F2 | `学科：…` `班级：…` `观课教师：…` |
| A4:B4 / **C4:F4** | 标签"小组任务" / 任务描述（≤ 45 字） |
| A5:B5 / **C5:F5** | 标签"小组人数" / 人数（数字，默认 4） |
| A6:B6 / **C6:F6** | 标签"小组工作时间" / 分钟数（数字） |
| A7:F7 | 小标题"小组分工情况"，固定 |
| A8 / B8:C8 / D8 / E8 / F8 | 成员A–成员E 标签，固定 |
| **A9 / B9 / D9 / E9 / F9** | 分工职责（每条 ≤ 25 字，按成员顺序） |
| A10:F10 | 小标题"小组工作情况"，固定 |
| A11 … F11 | 成员标签，固定 |
| **A12 / B12 / D12 / E12 / F12** | 工作情况（每条 ≤ 35 字，按成员顺序） |

- 只观察 **1 个小组**，人数与成员条数必须一致：4 人就写 4 条，第 5 组（成员E）留空。
- 分工要落到角色（组长／操作员／记录员／检查员／汇报员），工作情况要写"做了什么 + 做得怎样"，不能和分工重复。
