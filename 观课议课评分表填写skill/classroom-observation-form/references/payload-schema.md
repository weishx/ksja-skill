# payload 结构（fill_form.py 的输入）

**一节课 = 一份文件 = 一个 payload。** 三个顶层键，全部必需：

| 键 | 类型 | 作用 |
|---|---|---|
| `meta` | object | 表头公共信息：`date`（`2026-10-22` 或 `10月22日`）、`content`、`subject`、`class_name`。可选 `date_text`（不写自动生成"10月22日"）。 |
| `teachers` | array / object | **6 个子表各由谁填**。给数组就按子表顺序分配；给对象就显式指定。 |
| `sheets` | object | 六个子表的内容，键名必须是 `师生问答`、`教师提问`、`学生学习活动`、`小组合作教师行为`、`小组合作组员行为`、`课堂评价观察表`。缺的子表会被清空，**六表都要给**。 |

`teachers` 两种写法（名单多于 6 位时，多出来的老师不填表；不足 6 位会直接报错）：

```json
"teachers": ["王敏", "饶力高", "赵丽", "杨梦雪", "彭丽春", "王好好"]
```
按这个固定顺序对应：`师生问答 → 教师提问 → 学生学习活动 → 小组合作教师行为 → 小组合作组员行为 → 课堂评价观察表`

```json
"teachers": {"师生问答": "王敏", "教师提问": "饶力高", "学生学习活动": "赵丽",
             "小组合作教师行为": "杨梦雪", "小组合作组员行为": "彭丽春", "课堂评价观察表": "王好好"}
```
同一位老师可以出现在两张表里（兼填），但每个子表都要有人。

各子表的键与容量上限：

| 子表 | 键 | 上限 |
|---|---|---|
| 师生问答 | `conclusion`（4 行文本，`\n` 分隔） | — |
| 教师提问 | `questions[]`：`no` `q` `target` `answer` `openness` `reconstruct` | 5 条 |
| 学生学习活动 | `participation` `thinking` `cooperation` `generativity` `achievement` | — |
| 小组合作教师行为 | `analysis`（3 行，`\n` 分隔） | — |
| 小组合作组员行为 | `task` `size` `minutes` `members[]`（`duty` `work`） | 5 位成员 |
| 课堂评价观察表 | `items[]`：`activity` `statement` `standard` `mode` `effect` | 3 条 |

> 换行用 `\n`，不要用 `\r\n`。成员标签（成员A–成员E）由模板固定，`members` 只给 `duty` 和 `work`，顺序对应 A–E。

---

## 完整示例（可直接运行，生成 1 份文件、6 张表署 6 位老师）

```json

  "meta": {
    "date": "2026-10-22",
    "content": "平行四边形的面积",
    "subject": "数学",
    "class_name": "503"

    },
    "教师提问": {
      "questions": [
        {"no": "问题一", "q": "平行四边形的面积，你打算怎么求？先猜一猜。", "target": "集体", "answer": "集体回答 + 个别补充", "openness": "有向且开放", "reconstruct": "无需重构"},
        {"no": "问题二", "q": "把平行四边形转化成长方形，是沿着哪条线剪的？", "target": "个别", "answer": "单个学生作答", "openness": "有向不开放", "reconstruct": "你能指着图说一说，为什么一定要沿着高剪开，斜着剪行不行？"},

        {"no": "问题四", "q": "长方形的长和宽，分别对应平行四边形的什么？", "target": "个别", "answer": "学生独立作答", "openness": "有向且开放", "reconstruct": "无需重构"},
        {"no": "问题五", "q": "为什么面积是底乘高，不是底乘邻边？", "target": "个别", "answer": "个别作答 + 同伴补充", "openness": "有向且开放", "reconstruct": "你能用刚才剪拼的图形，量一量邻边和高的长度，说说它们为什么不一样吗？"}

    },
    "学生学习活动": {
      "participation": "43/48（约 90%），大部分学生主动动手剪拼、填写学习单，有 5 名学生等待同伴操作，参与积极性不高，偶尔分心",
      "thinking": "多数小组能通过剪拼得出“底×高”，但只有 12 人能说清“转化前后面积不变”的道理，思考多停留在操作层面，深度不足",
      "cooperation": "小组内分工较顺，4 个小组出现个别学生包办剪拼、其余成员只观看的情况，交流不够充分",
      "generativity": "有 2 个小组提出沿对角线剪也能拼出图形，但未进一步验证，未形成新的成果",
      "achievement": "88% 学生能正确用底乘高求面积，个别学生把邻边当作高，基本达成活动目标"
    },
    "小组合作教师行为": {
      "analysis": "1、高效的引导者还是缺席的管理者？\t整体是引导者，能在关键处追问“为什么沿高剪”，但巡视时对 1 个小组的争议未及时回应\n2、更倾向于介入指导还是放手观察？\t先放手观察约 4 分钟再介入，介入时机基本合适，个别小组被连续指导 2 次，略有打断\n3、能均衡关注所有小组，还是固定关注某几个小组？\t8 个小组中巡视到 6 个，靠窗 2 个小组停留时间明显不足"

      "size": 4,
      "minutes": 8,
      "members": [
        {"duty": "组长：负责安排剪拼顺序，汇总组内结论，代表小组汇报", "work": "有序组织每人发言，及时把组内结论记录到学习单，汇报时表达清楚，参与积极性高"},
        {"duty": "操作员：负责沿高剪开并平移拼摆", "work": "能准确沿高剪开，拼摆时对齐顶点，主动说明“面积没有变”，任务完成顺畅"},

        {"duty": "检查员：负责核对数方格结果与公式计算是否一致", "work": "能用数方格验证公式结果，发现同伴一处计算错误并提醒改正，配合较好"}
      ]
    },
    "课堂评价观察表": {
      "items": [
        {"activity": "评价一：剪拼方法的汇报评价", "statement": "教师口头点评小组汇报的操作过程", "standard": "无细化标准，只判断“拼得对不对”，教师仅说“很好，请回座位”", "mode": "师生", "effect": "基本有效，重构：“你们沿着高剪开再平移，长方形就拼出来了，能说说为什么面积没变吗？”"},
        {"activity": "评价二：学习单互批", "statement": "同桌交换学习单核对答案", "standard": "仅对答案打勾叉，没有说清错在哪里", "mode": "生生", "effect": "不够有效，重构：“请给同桌圈出错的那一步，并用一句话告诉他应该沿着哪条线对应。”"},
        {"activity": "评价三：公式推导自评", "statement": "学生用“星级”自评是否会用公式", "standard": "无明确自评依据，只凭感觉打星", "mode": "自评", "effect": "无效，重构：“请对照三条标准打星：①我能说出公式怎么来的□ ②我能找准底和高□ ③我能算对面积□。”"}
      ]
    }
  }

```
